# akh.cx

Personal blog on Jekyll and GitHub Pages.

## Footnotes

A footnote is the usual Markdown one:

```markdown
text[^name]

[^name]: Note.
```

On the site the text gets a small grey number over the line, and the note with the same number stands in the right margin (on a narrow screen it opens with a tap on the number). The list of footnotes at the end of the post is not shown. A term is explained with a footnote too. A fix is a footnote as well, with the old text crossed out inside it: `[^name]: Was: <del>old text</del>. Why.` To put a picture in the note, add `![](/assets/img/pic.png)` to its text. Also made by `assets/js/notes.js`.
